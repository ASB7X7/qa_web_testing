# API Test Cases

## TC_API_001

**Название:** Получение списка пользователей

**Метод:** GET

**URL:** /users

### Ожидаемый результат

- HTTP 200
- Ответ в формате JSON
- Возвращается список пользователей

## TC_API_002

**Название:** Создание новой записи

**Метод:** POST

**URL:** /posts

### Ожидаемый результат

- HTTP 201
- Создан новый объект
- В ответе присутствует поле id
