# API Testing

Практика тестирования REST API с помощью Postman.

## Выполненные запросы

### GET /users

Получение списка пользователей.

Проверено:

- Статус ответа 200 OK
- Возвращается JSON
- Получен список пользователей

### POST /posts

Создание новой записи.

Проверено:

- Статус ответа 201 Created
- Возвращается созданный объект
- Сервер присваивает id
