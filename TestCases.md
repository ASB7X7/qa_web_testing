# Test Cases

## TC-001 Авторизация с корректными данными

**Предусловие:**
Пользователь находится на странице авторизации.

**Шаги:**

1. Ввести корректный логин.
2. Ввести корректный пароль.
3. Нажать кнопку Login.

**Ожидаемый результат:**

Пользователь успешно авторизован и открыт каталог товаров.

## TC-002 Авторизация с неверным паролем

**Предусловие:**
Пользователь находится на странице авторизации.

**Шаги:**

1. Ввести корректный логин.
2. Ввести неверный пароль.
3. Нажать Login.

**Ожидаемый результат:**

Отображается сообщение об ошибке.
Пользователь остается на странице входа.

## TC-003 Авторизация с пустым логином

**Предусловие:**
Пользователь находится на странице авторизации.

**Шаги:**

1. Оставить поле Login пустым.
2. Ввести пароль.
3. Нажать Login.

**Ожидаемый результат:**

Появляется сообщение о необходимости заполнить логин.


## TC-004 Добавление товара в корзину

**Предусловие:**
Пользователь авторизован.

**Шаги:**

1. Открыть каталог товаров.
2. Нажать Add to cart у любого товара.

**Ожидаемый результат:**

Товар успешно добавлен в корзину.
Счетчик корзины увеличился на 1.

## TC-005 Удаление товара из корзины

**Предусловие:**
В корзине находится один товар.

**Шаги:**

1. Открыть корзину.
2. Нажать Remove.

**Ожидаемый результат:**

Товар удален из корзины.
Корзина стала пустой.
